# 课时小账微信小程序需求说明书

*微信云开发版本  v1.0  2026年9月10日*

## 1 产品目标与前置文档

在网页版课时费计算能力基础上，提供面向老师的微信小程序“课时小账”。用户在手机上录入月度课时、核对阶梯明细，自主决定是否保存结果；个人计费配置和已保存记录通过微信云开发保存在云端，按微信用户独立隔离。名称为产品暂定名。

### 1.1 引用的网页版需求文档

本文件的计费基线为[《月度课时费计算器需求说明书》](web.md)，版本 v1.0，日期2026年9月10日，以下称“网页版需求”。本文件定义微信小程序的界面、身份、云端配置与历史管理需求，与网页版需求配套使用。

| 网页版需求章节 | 微信小程序版引用与处理 |
| --- | --- |
| 第1.3节及第2至3节 | 继承计费规则、默认价格、工时精度，以及已确认的排序与舍入规则。 |
| 第4至5节 | 继承双向换算、校验、阶梯明细、每次结果末尾的计费表；按移动端重新组织页面。 |
| 第1.2节及第6节 | 当前版本新增用户身份、云端配置与手动保存历史；配置以云端为准，本地只作缓存。 |
| 第7至8节 | 复用A01至A15算法验收；B类交互按本文件调整，新增云端与多用户验收。 |

冲突处理：计费业务规则仍以网页版需求为基线；小程序界面、身份、持久化及历史管理以本文件为准。当前版本不要求改造网页版，也不自动迁移浏览器 localStorage 或打通网页账号。

### 1.2 当前版本交付范围

必须交付微信小程序、微信云开发环境下的云函数和云数据库配置。核心功能包括月度计算、个人计费配置、手动保存、历史列表与详情、删除自己的记录，以及同一微信用户在多设备上的云端数据读取。

当前版本不扩展排课、学生档案、团队共享、工资发放、税务计算、自动备份每次试算、报表导出或订阅提醒。历史记录可作为核对材料，不自动视为已发放工资。

### 1.3 核心保存原则

“计算”只生成当前会话内的结果，默认不上传输入或结果、不新增历史记录；“保存到云端”才提交该次结果。“保存计费配置”是独立操作，不会连带保存当前计算结果。首次初始化个人默认配置属于配置建立，不属于自动保存计算记录。

## 2 计费继承与用户身份

### 2.1 保持一致的核算规则

沿用网页版需求第2至3节：全月所有年级和班型共用六个累进阶梯，低年级先填；每节固定2小时；一对一、一对二、一对三分别使用1.0、1.2、1.3的费用系数，系数不改变阶梯工时。只开放六阶梯×四年级组共24个基础单价的配置。

初始单价严格复制网页版需求第2.1节，第二个价格组为六年级、初一、初二。小时支持0.01的整数倍，节数支持0.005的整数倍；金额逐条最终明细四舍五入到分，再相加。前端与云函数复用同一份带版本号的纯计算模块。

沿用网页版需求已确认的结算口径：按实际年级从低到高填充阶梯，同年级按“一对一 → 一对二 → 一对三”排序，逐条最终明细四舍五入到分。固定规则版本必须进入配置和记录快照。

### 2.2 微信用户绑定

在小程序中通过微信云开发的可信调用身份识别当前微信用户，不要求用户另行注册账号或输入密码。每位用户拥有自己的配置及记录；同一微信账号进入同一小程序及正式环境，可在不同设备读取同一份云端数据。

身份凭据由云函数从微信调用上下文取得，例如该小程序作用域内的 OPENID。数据库归属标识由服务端生成或填充，任何云函数都不得相信客户端传入的 openid、ownerId 或 userId。具体 SDK 接口及适用版本作为开发联调核验项。

不以昵称、头像、手机号或设备标识作为账号主键；核心功能不依赖获取头像、昵称和手机号。跨小程序账号合并不在当前版本范围内，不要求通过 UnionID 关联其他应用。

### 2.3 首次进入与账号切换

首次启动先识别身份并读取个人配置。确认该用户无配置时，在云端幂等创建默认配置及初始版本；多设备同时首次进入也只能得到一份个人当前配置。只有确认“无配置”才初始化，网络失败不能被当作首次使用。

身份未确认时不展示任何上次用户的配置缓存、输入或记录。识别出账号变化后，立即清除页面内存中的上一账号输入和结果，切换缓存命名空间，再加载当前账号资料。无法确认身份时禁止所有云端保存及历史读取。

### 2.4 用户数据隔离标准

用户A不能读取、修改或删除用户B的配置、配置版本或记录，知道B的记录ID也不例外。查询、详情、分页、保存、配置更新和删除都必须在服务端校验调用者归属；仅在前端过滤用户不是合格实现。

## 3 小程序移动端页面

### 3.1 信息架构与视觉

| 底部入口 | 主要内容 | 主要操作 |
| --- | --- | --- |
| 计算 | 月份、课时输入、工时合计、结果概览 | 添加课时、计算课时费、查看明细、保存到云端 |
| 记录 | 月份筛选、已保存记录卡片、保存时间 | 查看记录、重新试算、删除记录 |
| 设置 | 我的计费表、规则说明、云端同步状态 | 编辑价格、保存计费配置、恢复默认 |

使用浅色背景、白色内容卡片和绿色主要按钮。主金额使用大号数字；“未保存”“已保存”“待重算”同时用文字表达。用户页面使用“已同步”“保存失败”等自然语言，不显示 OPENID、云函数名称或数据库版本字段。

### 3.2 课时输入

首页默认当前本地月份。采用“添加课时”打开底部面板：先选实际年级，再选一对一至一对三，输入节数或小时，两者实时换算。首页仅显示已添加的组合卡片，避免让手机用户一次面对36行空表。允许的年级与班型组合仍与网页版需求一致。

卡片展示“六年级 · 一对二”、两个数量输入框及删除按钮。再次选择已有年级与班型时定位该卡片进行编辑，不另建重复项。删除有数值卡片需确认；所有输入校验和换算精度沿用网页版需求第4.3节。

底部固定区域显示总小时、折算总节数及“计算课时费”。月份切换不加载历史，也不自动清空输入；存在输入时提示“月份已切换，请核对课时”。历史记录的复用须由用户在详情页显式发起。

### 3.3 结果与阶梯明细

点击计算后在本页生成结果卡，显示月份、课时费、总工时及“未保存”。结果有效时提供独立的“保存到云端”按钮；原有计算按钮可改为“重新计算”。保存按钮不得预先勾选或与计算合并。

点击“查看计算明细”进入详情页。按阶梯纵向排列，展示工时构成、每条“小时×单价×系数＝金额”、阶梯小计及总计。末尾附完整计费表，可按阶梯卡片呈现全部24个价格，并注明班型系数、每节时长、排序和舍入规则。

### 3.4 移动端适配要求

覆盖约320至430逻辑像素宽度的手机竖屏，主要操作触达区建议至少44×44逻辑像素。数字输入调起合适键盘；固定按钮避让键盘、底部安全区和底部导航。顶部内容避让微信导航及胶囊区域。

主流程不依赖横向滚动，不把桌面宽表直接缩小。长金额、较大系统字体和长年级名称必须换行或自适应，不截断关键数字。iOS与Android均进行真机录入、键盘遮挡及返回操作验收。

## 4 手动保存与结果状态

### 4.1 从试算到保存

一次成功计算冻结输入、完整计费配置、算法规则版本和结果，形成一个计算实例。点击“保存到云端”提交这个实例，而非再次读取最新设置替换价格。保存成功后显示“已保存”和服务端保存时间，并提供“查看记录”。

云端记录必须一次性包含输入、逐阶梯明细、汇总结果及配置快照；不能只保存总金额或当前配置的引用。只有服务端确认写入成功才显示已保存。保存配置与保存记录使用不同按钮和提示。

| 状态 | 界面表现 | 允许的操作 |
| --- | --- | --- |
| 尚未计算 | 课时录入中 | 计算；不能保存结果 |
| 已计算未保存 | 未保存，可查看明细 | 保存到云端；重新计算 |
| 输入或配置已变化 | 待重算，旧金额标为上次结果 | 重新计算；禁用旧结果保存 |
| 正在保存 | 保存按钮显示进度且防重复点击 | 本次请求冻结，不允许改动提交内容 |
| 已保存 | 已保存及保存时间 | 查看记录；修改输入后重新计算 |
| 保存失败或状态未知 | 明确失败或正在确认保存状态 | 保留结果，重试或查询本次请求结果 |

### 4.2 不重复保存也不覆盖历史

同一计算实例使用稳定的保存请求标识。重复点击、超时重试和响应丢失后的查询，应返回同一条记录，不得重复插入。服务端按“用户归属＋请求标识”保证唯一；相同标识但内容不同必须拒绝。按钮禁用不能替代服务端防重复处理。

成功后再次点击同一实例只打开既有记录。用户主动重新计算会产生新实例，仍需点击保存才新增记录。同一个月份允许多条记录，不按月份覆盖；它们可能只是不同核算方案，列表不把同月全部记录自动相加当作工资。

### 4.3 未保存数据与离开页面

切换底部入口时可在当前小程序进程内保留输入与结果，但不写入云端或本地持久化。清空、替换输入、可拦截的离开操作应提示未保存内容；系统终止进程无法保证提示，页面须说明“未保存试算关闭后可能丢失”。

不建立离线自动上传队列，不在恢复网络、切后台或退出时自动保存。云请求已经发出后可能在服务端完成，即使客户端随后断网也不能断言未保存，应以该请求标识核实。

### 4.4 数据一致性

保存期间云函数按冻结配置版本复算并校验结果，不能直接相信客户端总金额。若客户端与服务端不一致，拒绝本次入库，提示更新或重新计算；用户核对新结果后再次主动保存。已保存的历史只读展示，不因算法升级自动重算或改写。

## 5 云端计费配置与多设备同步

### 5.1 编辑与生效

每位用户维护一份当前计费表。设置页按六个阶梯折叠展示，每阶梯包含四个价格输入。进入编辑时创建草稿；可编辑24个基础单价，金额校验沿用网页版需求第6.2节。恢复默认先确认并仅替换草稿，点击“保存计费配置”才提交。

云端保存成功后新价格生效，并更新当前用户的本地缓存。取消或保存失败都保留原生效配置；失败时保留编辑草稿并提供重试。当前版本不提供未同步自定义价格直接生效的路径，避免用户把未保存的价格误认作跨设备配置。

保存配置只影响后续计算。当前存在试算结果时标记待重算；已保存历史中的金额及计费表永久保持原样，除非用户删除整条历史记录。

### 5.2 配置版本与快照

每次实际价格变更在云端生成不可变配置版本，并更新个人当前版本指针；无变化保存不必新增版本。版本中包含完整价格、阶梯、年级映射、班型系数、每节时长及排序与舍入规则，版本归属同样隔离。

计算时绑定当时选用的版本。保存结果时，即使另一设备已经更新当前配置，仍可使用属于本人的原版本保存该次试算，并在详情标明采用的配置时间；云函数不得偷换成最新版本。记录自身还需内嵌完整快照，不能依赖版本引用才能看懂历史。

### 5.3 多设备冲突

编辑配置时携带读取到的修订号。服务端在同一事务中校验修订号、写入新版本并更新当前指针；若已被其他设备修改，返回冲突，不用后提交的草稿静默覆盖云端。

冲突提示“计费表已在其他设备更新”。保留本机草稿供对照，提供“加载最新配置”；用户重新确认并编辑后再次保存。当前版本不做逐单元格自动合并，也不提供默认强制覆盖。

### 5.4 加载与弱网策略

| 情形 | 处理要求 |
| --- | --- |
| 在线且身份已确认 | 启动及进入设置时读取云端；无脏输入时更新缓存和生效配置。 |
| 已有输入时发现远端新版本 | 提示有新价格，用户选择应用并重算或继续本次旧版本；不悄悄替换试算配置。 |
| 临时断网且身份已确认 | 可使用该用户缓存的已同步配置在本地试算；保存记录及配置需联网重试。 |
| 身份未确认或无可用缓存 | 不展示私人缓存；可用内置默认表临时试算，明确提示默认价格；云功能不可用。 |
| 恢复身份或恢复联网 | 重新读取个人配置，不自动上传临时试算；临时默认试算需按个人配置重新计算后才能保存。 |

缓存按可信用户标识和云环境分区，仅保存最近已同步配置。历史列表和详情使用会话缓存，重新进入时从云端拉取；正式环境与测试环境的数据不得混用。

## 6 历史记录管理

### 6.1 记录列表

“记录”页只显示当前微信用户主动保存成功的记录。默认按服务端保存时间倒序，支持按结算月份筛选、下拉刷新和分批加载，建议每页20条。分页同时使用保存时间与记录ID作为稳定顺序，避免时间相同导致漏项或重复。

卡片展示结算月份、课时费、总小时、折算节数、保存时间和配置时间标签。同月多条独立展示，不静默替换。空列表显示“暂无已保存记录”，并引导前往计算页；加载失败显示重试，不能伪装成空列表。

### 6.2 记录详情

详情展示当次输入摘要、逐阶梯计算过程、总额、本地计算时间与服务端保存时间。页面末尾完整展示该记录内嵌的计费表及规则快照，并注明“本记录使用的计费表”。即使用户当前配置已变，历史仍按快照展示。

不提供直接修改历史金额、输入或快照的操作。显示金额以已保存明细为准，不用最新算法现场重算历史。新版本无法识别旧记录结构时，给出兼容提示并保留数据，不显示错误金额或默认价格代替旧快照。

### 6.3 基于记录重新试算

详情提供“按当前计费表重新试算”。用户点击后将历史输入复制到计算页草稿，保留原结算月份，绑定当前个人配置。覆盖已有输入前确认，明确提示“已复制课时，使用当前计费表，请重新计算”。

重新试算不会修改原记录；结果默认未保存，只有再次点击保存才新增记录。新记录可保存来源记录ID用于追溯，但其输入和快照独立存在，原记录删除也不影响新记录查看。

### 6.4 删除记录

只允许删除本人记录。点击删除后展示月份、金额和保存时间并二次确认；成功后移除列表项并退出该详情。删除整条记录时连同内嵌输入、明细和快照一起删除，不改变当前计费配置或其他记录。

删除失败保留原展示并提示重试。当前版本不提供回收站。已不存在的本人记录可返回已删除，重复删除应安全；无归属权限与不存在对普通用户统一展示“记录不存在或不可访问”，不泄露其他用户是否拥有该记录。

### 6.5 调价后的核对示例

| 步骤 | 预期表现 |
| --- | --- |
| 用默认表计算一年级20小时＋六年级20小时 | 结果1,350.00元，未保存；尚无新云端记录。 |
| 点击保存到云端 | 新增一条1,350.00元记录，保存完整旧表，其中首阶梯小学单价为15元。 |
| 将该单价改为20元并保存配置 | 历史仍为1,350.00元，详情末尾仍为15元。 |
| 从历史复制并按当前表重新计算 | 新结果1,450.00元；默认不保存，旧记录不变。 |
| 主动保存新结果 | 同月有两条独立记录，分别为1,350.00元和1,450.00元。 |

## 7 微信云开发数据与接口

### 7.1 架构要求

微信小程序负责移动端交互和本地试算；微信云函数负责可信身份、数据校验、保存时复算、权限校验及并发控制；微信云数据库负责个人配置、配置版本与计算记录。无需另建传统业务服务器，当前范围无附件，因此云文件存储不是必选依赖。

### 7.2 建议集合

| 集合 | 主要内容 |
| --- | --- |
| user_configs | 用户归属、当前配置版本ID、递增修订号、创建和更新时间。每用户一份当前指针。 |
| config_versions | 用户归属、版本ID、结构和规则版本、完整24格价格与固定规则、创建时间。已建立版本不覆盖修改。 |
| calculation_records | 用户归属、记录ID、保存请求标识、结算月份、输入快照、结果明细及汇总、完整配置快照、配置版本ID、算法版本、本地计算时间、服务端保存时间、可选来源记录ID。 |

工时使用百分之一小时整数，金额使用分整数；班型系数以分子和分母表达。快照须含字段名称和稳定枚举映射，能脱离当前配置还原含义。服务端时间用于保存排序，本地时间仅用于描述当时试算，不可当作审计顺序依据。

### 7.3 云函数职责建议

| 操作 | 输入与服务端行为 |
| --- | --- |
| 初始化并读取配置 | 无客户端用户ID；从调用上下文取身份，读取或幂等建立个人默认配置。 |
| 保存计费配置 | 接收价格草稿、预期修订号及请求标识；校验归属、字段和并发版本，原子更新。 |
| 保存计算记录 | 接收计算实例ID、月份、输入、配置版本ID、客户端校验摘要及规则版本；按本人历史配置复算，核对后原子创建完整记录。 |
| 查询记录与详情 | 接收月份筛选、游标或记录ID；服务端强制加本人归属条件，返回必要字段。 |
| 删除本人记录 | 接收记录ID；校验归属后删除，重复请求不影响其他数据。 |

### 7.4 原子性与防重复

结果输入、明细和快照嵌入同一条记录，保存要么全部成功，要么不产生该记录。通过唯一约束或确定性ID加条件创建保证同一用户同一保存请求只落一条；不能采用存在竞态的“先查询再无条件新增”。

配置更新在事务内完成版本创建和当前指针切换。对记录设置本人归属、月份、保存时间和ID相关查询索引；分页及数量上限必须由服务端校验。相同请求标识重试返回既有成功结果，不能误报为新冲突。

## 8 权限边界与异常处理

### 8.1 服务端必须执行的校验

建议小程序端对业务集合禁止直接读写，所有数据经云函数访问。云函数使用服务端权限，因此不得只依赖数据库客户端安全规则；每个操作都显式获取可信调用身份，并校验数据归属。配置版本、来源记录及分页参数同样不能绕过归属限制。

服务端校验年级、班型、数值精度、24个价格完整性、月份格式、规则版本及请求体大小；拒绝未知字段对归属和时间字段的覆盖。由服务端读取本人不可变配置版本并生成快照，客户端传来的快照或金额仅作一致性核对。

不把管理员凭据放入小程序包，不开放跨用户浏览入口。运行日志仅记录请求标识、错误类型和必要性能信息，不整包记录未保存输入、金额明细或个人价格；本地计算本身不调用上传类接口。

### 8.2 错误与恢复行为

| 异常 | 必须表现 |
| --- | --- |
| 身份不可用 | 提示暂时无法读取个人数据；禁止云端操作，可使用明确标注的默认表试算。 |
| 云端配置读取失败 | 使用本人已确认缓存或内置默认试算路径；不能用默认值覆盖云端。 |
| 保存断网或超时 | 保留当前结果；显示未确认状态，按同一请求标识查验或重试；不重复生成记录。 |
| 配置并发冲突 | 保留草稿，提示其他设备更新；加载最新后重新编辑，不静默覆盖。 |
| 复算或版本不一致 | 拒绝保存，提示重新计算或更新小程序；不得改金额后悄悄保存。 |
| 云端服务或额度异常 | 提示暂时无法同步，保留会话草稿并允许本地试算；不显示保存成功。 |
| 无权限或记录不存在 | 提示不可访问；不返回对方记录内容、金额或拥有者信息。 |

### 8.3 请求与生命周期

保存配置和记录成功时以服务端响应为准。若响应丢失，界面通过本次请求标识确认状态；网络恢复不得将未提交的试算自动变成保存请求。连续触发请求时，旧响应不得覆盖新账号或新计算实例的页面状态。

当前进程被微信回收后，未保存结果允许丢失；已保存记录重新从云端查询。正在保存时强制退出可能出现服务端成功但本机未收到响应，重新进入记录页应能看到成功记录。不能承诺平台无法保证的退出拦截或后台执行。

### 8.4 开发与运行要求

测试与正式云环境隔离。交付时固定并记录小程序基础库、云函数运行时及SDK版本，核验可信身份接口、数据库事务、权限规则和索引行为。云开发环境由项目所有者持有，交付包含部署说明、版本升级及恢复操作说明；不预设云资源永久免费。

## 9 验收用例与交付标准

网页版需求第7节A01至A15继续作为前端与云函数复算的一致性用例，统一按已确认的排序与舍入规则验收。以下为当前版本新增验收，使用两个真实微信测试账号及至少两台设备验证隔离与同步。

| 编号 | 验收场景 | 预期结果 |
