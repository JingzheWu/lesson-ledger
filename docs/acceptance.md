## 依赖审计记录

2026-09-12 对云函数生产依赖执行 `npm audit --omit=dev`，报告6个受影响依赖项（5 high、1 moderate），来源是官方 `wx-server-sdk@4.0.2` 的传递依赖 `axios@0.27.2`、`lodash.set`、`lodash.unset` 及其父依赖链。参考[Axios公告](https://github.com/advisories/GHSA-jr5f-v2jv-69x6)、[lodash.set公告](https://github.com/advisories/GHSA-p6mc-m468-83gw)。这不等同于已证明本应用可被利用，也不能宣称依赖审计无告警。

当前业务不接收任意网络URL、SDK选项或数据库字段路径；所有查询和写入字段由服务端生成，输入字段白名单验证后才参与计算。未使用 `npm audit fix --force` 建议的旧SDK降级，以免改变身份和事务行为。正式部署前需跟踪官方兼容修复并完成云端回归；依赖风险尚未由本次本地测试消除。
