# 小程序 SVG 素材清单

目前页面混用了 CSS 边框绘制、加减号字符和记录占位符。待提供素材后统一替换；本轮仅盘点，图标尚未改动。

| 文件名 | 图形 | 使用位置 |
| --- | --- | --- |
| `home.svg` | 首页房屋 | 分享明细左上角返回首页 |
| `chevron-right.svg` | 右向折线箭头 › | 月份、年级、班型、查看记录入口；旋转为左箭头用于返回，向下用于筛选及展开，向上用于折叠 |
| `plus.svg` | 加号 | 添加课时 |
| `file-text.svg` | 带文字横线的文档 | 记录列表的空状态，替换当前的 ▤ 字符 |

同系列、单色线性 SVG，建议 `viewBox="0 0 24 24"`、描边约2、无底色。颜色和显示尺寸会在接入时统一处理。展开/收起计划采用上下折线箭头；如果最终选用加减号方案，补充同系列 `minus.svg` 即可。

底部“计算 / 记录 / 设置”当前为纯文字导航，微信原生提示框及成功提示使用系统图标；本次替换范围为上表的页面图标。
